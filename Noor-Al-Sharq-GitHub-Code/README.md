# Noor Al Sharq Laundry Website

Responsive static website with service cards, pricing estimates, WhatsApp and phone links, and branch location links.

## Run locally
Open `index.html` in your browser. No installation or build step is needed.

## Upload to GitHub
1. Extract this ZIP.
2. Create a GitHub repository.
3. Choose Add file > Upload files.
4. Upload all extracted files and the assets folder (not the ZIP). Keep index.html at the repository root.
5. Commit the files.

## Publish with GitHub Pages
In repository Settings > Pages, select Deploy from a branch, choose main and / (root), then Save.

## Files
- index.html: page content
- style.css: desktop and mobile styles
- app.js: page interactions and mobile contact controls
- prices.js: price list and estimate calculation
- assets/: logo and website images

Contact numbers, branch links and content can be edited in index.html. Service descriptions are in app.js; prices are in prices.js.
